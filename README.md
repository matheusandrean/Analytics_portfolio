## Credit Risk Analysis

**Análise de risco de crédito com Machine Learning utilizando dados do Statlog (German Credit Data).**

### Importância para o Negócio

Este projeto avalia a probabilidade de inadimplência de clientes para suportar decisões estratégicas na concessão de crédito. Aplicamos um pipeline completo de análise de dados, desde a exploração inicial até a modelagem e avaliação preditiva.

### Principais Métricas do Modelo
- **Acurácia**: 76%
- **AUC-ROC**: 0.81
- **Precisão (Class 1 - Risco)**: 74%
- **Recall (Class 1 - Risco)**: 71%

### Resultados e Insights
- Identificamos que variáveis como **Credit_amount**, **Duration_in_month** e **Age_in_years** têm maior impacto na inadimplência.
- O modelo preditivo otimiza a gestão de crédito, reduzindo perdas financeiras.

**Projeto no GitHub**: [Credit Risk Analysis](https://github.com/matheusandrean/Analytics_portfolio/blob/main/ML/credit_risk_analysis/Analise_de_credito/credit_risk_analysis.ipynb)
